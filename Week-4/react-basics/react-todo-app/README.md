# Week-4 Summary

## What I did:

I learned React fundamentals by creating annotated notes covering JSX, functional components, props, useState, useEffect, and conditional/list rendering. I also built a fully functional to-do app in React, which was a great comparison to the vanilla JS version I built in Week 1...

## What I learned:

I learned that React is all about declarative UI-instead of manually manipulating the DOM, I just describe what the UI should look like based on the current state, and React handles the updates. I also learned how to properly use keys in lists, how to handle forms with controlled components, and how to structure a React app with multiple components...
